## 免备案、免实名、内容监管，三条线各管各的

实名认证核的是“你是谁”，在账号注册和下单环节要求提交身份证、护照或营业执照。ICP 备案核的是“这个网站能不能在中国大陆境内公开访问”，针对的是网站和域名。两条线各管各的，不存在“因为免实名所以免备案”这种因果关系。

境外服务器通常既免实名又免备案。免备案的原因只有一个：机房不在中国大陆境内，不归工信部管。部分境外服务商出于自身合规要求仍可能让你做身份验证，这不影响它免备案的性质。

国内服务器有三种组合，最容易被忽略的是第三种：

| 场景 | 实名 | 备案 |
| --- | --- | --- |
| 国内服务器 + 公开网站 | 必须 | 必须 |
| 国内服务器 + 非网站业务（内部数据库、API 接口、AI 训练、游戏后端、自动化测试） | 必须 | 不一定 |
| 境外服务器 | 通常免 | 免 |

你在国内机房买一台服务器，只跑内部数据库、API 接口、模型训练或者自动化测试，不绑定域名对外渲染网页，就不涉及 ICP 备案。但只要把域名解析过去、对外开放 80/443，就必须先备案，否则端口会被机房系统自动拦截。

内容监管是另一回事。境外机房也要遵守机房所在地法律，香港、美国、日本节点都明确禁止违法违规内容，违者封停。免备案省的是流程，不是责任。
